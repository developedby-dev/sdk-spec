# 데브 SDK 공통 동작 명세 · 적합성 시나리오

데브 라이선스 API의 공식 SDK가 함께 따르는 동작 명세와, 모든 언어의 SDK가 통과하는 적합성 시험 시나리오입니다.

- [공통 동작 명세](spec/README.md) · 기계 판독 규칙 [`spec/rules.json`](spec/rules.json)
- [적합성 시험 시나리오](conformance/scenarios)

SDK 없이 HTTP만으로도 모든 기능을 쓸 수 있습니다. 판매자 안내서는 https://developedby.dev/sell/docs 에 있습니다.
